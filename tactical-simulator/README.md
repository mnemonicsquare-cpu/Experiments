# Тактический симулятор

Самостоятельная браузерная тактика: один оперативник, три действия, семь зон, три авторских промышленных сектора. Русский интерфейс, ландшафтный режим телефона, сохранение боя без сервера.

## Запуск

Node.js 22+, npm, Python 3 и Pillow. Из каталога `tactical-simulator`:

```sh
npm ci
python3 -m pip install Pillow==11.3.0
npm run assets
npm run dev
npm run test
npm run build
npm run simulate
```

`npm run simulate -- --battles 20` проводит 2520 боёв. По умолчанию — 7560. Отчёты находятся в `reports/balance-latest.md` и JSON. `npm run assets` воспроизводит оригинальные PNG/WAV (Python 3, Pillow).

## Структура

- `src/engine`: чистый TypeScript, RNG, правила, utility AI; не импортирует Phaser/DOM.
- `src/data`: определения оружия, брони, состояний и ручных графов карт.
- `src/render`: Phaser-сцена и Web Audio.
- `src/main.ts`, `src/ui`: интерфейс, прогнозы, локальное сохранение, обучение.
- `tests`: 71 проверка правил, включая детерминизм полного боя.
- `scripts`: генерация ассетов, симуляции, браузерная проверка.

Новое оружие добавляется в `WEAPONS` и селектор снаряжения. Поведение задают traits. Новая карта — объект `MapDefinition` в `maps.ts`: области, физические walk/ladder-связи, drop targets, механизмы и стартовые позиции. Добавьте оригинальный фон и превью.

## Отладка

Только намеренное добавление `?debug=tactical-4173` открывает кнопку DEV и граф маршрутов. Доступны seed, заданные d6, HP, броня, телепорт, состояния, AI scores и загрузка JSON боя. Обычный URL не предоставляет отладочные элементы и API.

## Публикация

`.github/workflows/tactical-pages.yml` проверяет тесты и сборку, сохраняет симуляционный отчёт и публикует `/tactical-simulator/`. GitHub Pages должен быть включён с источником **GitHub Actions** в Settings → Pages. Workflow пытается включить его автоматически; если GitHub запрещает первоначальную настройку токену Actions, её один раз выполняет владелец репозитория.

## Проверено

Production build, 71 unit test, Chromium: desktop 1440×900 и landscape 844×390, без ошибок console/runtime и горизонтального переполнения. Эмуляция размеров не заменяет проверку на физическом iPhone; такая проверка в этой сессии не выполнялась. Состояние баланса и ограничения подробно отмечены в BALANCE.md.

Все игровые изображения и звуки локальны, созданы процедурно. Сторонние игровые ассеты отсутствуют. Phaser и остальные библиотеки сохраняют свои лицензии.
